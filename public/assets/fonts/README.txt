Poppins (Latin) and Hind Siliguri (Bangla) - self-hosted WOFF2 files, SIL Open Font License 1.1.
  Both were designed by Indian Type Foundry (India). The owner first asked for no Indian fonts (2026-10-21), tried
  Kalpurush and Siyam Rupali (Bangladeshi), found they broke the design in many places, and decided to go back
  to these two. Bangla digits (০-৯) are drawn by the device's own Bangla font (see @font-face "Bangla Digits" in
  app.css) because Hind Siliguri's "১" looks like a blob. Phone numbers are shown with English digits.

Extra Bangla fonts the super admin may choose in the admin panel ("রং ও আকার" -> "বাংলা ফন্ট"; default stays
Hind Siliguri). Bengali subset only, one variable WOFF2 file each (weights 400-600), from Google Fonts,
SIL Open Font License 1.1 (licence text beside each file):
  noto-sans-bengali.woff2  Noto Sans Bengali (The Noto Project Authors)   OFL-noto-sans-bengali.txt
  anek-bangla.woff2        Anek Bangla (The Anek Project Authors, Ek Type) OFL-anek-bangla.txt
  baloo-da-2.woff2         Baloo Da 2 (The Baloo 2 Project Authors, Ek Type) OFL-baloo-da-2.txt
A browser downloads one of these only when it is chosen (an unused @font-face costs nothing).
