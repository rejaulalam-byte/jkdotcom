# কোডিং-নিয়ম (jorurikaj.com)

যে ডেভেলপার এই প্রজেক্টে কাজ করবেন, তাঁর জন্য। উদ্দেশ্য: কোড যেন সবসময় একই ধাঁচে থাকে এবং
নতুন কেউ দেখেই বুঝতে পারেন কোন অংশ কী করে। সাইটের পরিচিতি ও চালানোর ধাপ [README.md](../README.md)-তে।

## ১. কমেন্ট

- **ভাষা: বাংলা।** (সাইটের কনটেন্ট বাংলা, মালিক ও ক্লায়েন্টও বাংলায় কাজ করেন।) কোডের নাম —
  ফাংশন, ক্লাস, ভেরিয়েবল, CSS ক্লাস — ইংরেজিতে। PHPDoc-এর টাইপ-চিহ্ন (`@param`, `@return`, `@var`) যেমন আছে তেমন।
- **প্রতিটি নতুন অংশের শুরুতে একটা কমেন্ট:** নতুন সেকশন, নতুন ক্লাস, নতুন ফাংশন, নতুন CSS-ব্লক, নতুন JS-অংশ।
  কমেন্ট বলবে **কেন** (বা কী উদ্দেশ্যে)। কোড পড়েই যা বোঝা যায় তা আবার লিখবেন না
  (`// i এক বাড়াও` ধরনের কমেন্ট নয়)।
- অদ্ভুত বা চোখে পড়ার মতো মান থাকলে এক লাইনে কারণ লিখুন, যেমন `padding-top: 8rem; /* Figma: লোগো ফুটারের ১২৮px নিচে */`।
- যে পেইজ Figma থেকে বানানো, তার ভিউ-ফাইলের শুরুর docblock-এ Figma node-id লিখুন (যেমন `Figma node 2674-7`)।
- কাজ-চলার-পথের নোট, তারিখ, "মালিক বলেছেন" জাতীয় ইতিহাস কমেন্টে রাখবেন না; সেগুলো `CLAUDE.md` ও
  `PROGRESS.md`-এ। কমেন্টে শুধু বর্তমান নিয়ম ও তার কারণ।
- ব্যবহার-না-হওয়া কোড কমেন্ট করে রাখবেন না; মুছুন (git-এ ইতিহাস থাকে)।

## ২. PHP

- প্রতিটি ফাইলের শুরুতে `declare(strict_types=1);`। মেথডের প্যারামিটার ও রিটার্নে টাইপ দিন।
- নতুন পেইজ: কন্ট্রোলারের মেথড → `app/Views/pages/` ভিউ → `config/routes.php`-এ এক লাইন →
  লেখা `app/Content/defaults.php`-এ (কী-র নাম পেইজের নাম দিয়ে শুরু, যেমন `today.post.*`)।
  ভিউয়ে বাংলা লেখা সরাসরি বসাবেন না; `content('কী')` ডাকুন।
- ভিউয়ে প্রতিটি পরিবর্তনশীল মান `e(...)` দিয়ে escape করুন। SQL শুধু PDO prepared statement।
  নিরাপত্তার পুরো তালিকা README-তে।
- ডাটাবেসের কাজ `app/Models/*Repository.php`-এ; কন্ট্রোলারে SQL নয়। ডাটাবেস না থাকলে (ডেমো মোড)
  `DemoData` বা `storage/*.json` দিয়ে একই প্রবাহ চলবে।
- প্রতিটি পাবলিক ফর্মে: CSRF টোকেন, লুকানো `website` ফাঁদ-ঘর, `RateLimiter`, সার্ভারে যাচাই।
- বাংলা লেখার প্রতিটি ঘরে `data-bn` অ্যাট্রিবিউট এবং ফর্মে `partials/bn-switch.php` একবার।
- ফোন নাম্বার: ১১ সংখ্যা `01XXXXXXXXX` হিসেবে সংরক্ষণ; `normalize_phone()`, `mask_phone()`, `format_phone()` ব্যবহার করুন।

## ৩. CSS (`public/assets/css/app.css`)

- একটাই ফাইল। শুরুর সূচিপত্র দেখে সেকশন খুঁজুন। নতুন পেইজের স্টাইল ফাইলের নিচের দিকে
  নিজের নামে সেকশন খুলে (`/* ---- নাম (Figma node) ---- */`) লিখুন।
- ইনলাইন `style=""` চলবে না (Content-Security-Policy আটকায়)। সব স্টাইল ক্লাসে।
- ডেস্কটপে `1rem = পর্দার প্রস্থের ১/১২০` (১৯২০px-এ ১৬px)। Figma px ÷ ১৬ = rem। ১২০০px-এর নিচে মোবাইল/ট্যাবলেটের
  আলাদা নিয়ম, `@media (max-width: 1199px)`।
- **ফন্ট-সাইজের নিয়ম (নতুন পেইজ):** সাধারণ লেখা ২৪px; বাকি সব সাইজ Figma + ২px; শুধু ডেস্কটপে।
  কন্ট্রোলার `bodyClass` => `page-<নাম>` পাঠায়, CSS-এ `@media (min-width: 1200px) { body.page-<নাম> { --fs-body: 1.5rem; } }`।
  ফোনের সাইজ আলাদা।
- ফন্ট: Poppins + Hind Siliguri-ই থাকবে, বদলানো যাবে না। বাংলা অঙ্ক ডিভাইসের নিজের ফন্টে ("Bangla Digits")।
- রং ও মাপের মান `:root`-এর `--` ভেরিয়েবলে; একই মান বারবার সরাসরি লিখবেন না।
- থিমের রং অ্যাডমিন বদলাতে পারেন ("রং ও আকার", `/site-theme`), তাই টিল, সোনালি, কমলা আর মূল লেখার রং সবসময় ভেরিয়েবলে:
  `var(--teal)`, `var(--gold)`, `var(--amber)`, `var(--ink)`; স্বচ্ছ রূপ `rgba(var(--teal-rgb), 0.5)` বা `rgba(var(--ink-rgb), 0.5)`।
  সরাসরি `#125a6c` বা `rgba(18, 90, 108, …)` লিখবেন না, নইলে অ্যাডমিনের রং সেখানে পৌঁছাবে না।
- লেখার আকারও অ্যাডমিন বদলাতে পারেন (শতাংশে), তাই প্রতিটি নতুন `font-size` তার দলের গুণকে গুণ করে লিখুন:
  `font-size: calc(1.5rem * var(--k-body));` (২.৫rem-এর কম = `--k-body`, বড় শিরোনাম = `--k-head`;
  ক্যাপসুল `--k-pill`, মেনু `--k-nav`, বাটন `--k-btn`, ফুটার `--k-foot`)।
- ফর্মের উপাদান (`input`, `select`, `textarea`, `button`) সাইটের ফন্ট নেয় (`font: inherit`)।

## ৪. JavaScript (`public/assets/js/app.js`)

- JavaScript ছাড়াও সাইট চলতে হবে; JS শুধু বাড়তি আরাম। প্রতিটি অংশ নিজে নিজে বাদ পড়ে যদি তার উপাদান পেইজে না থাকে।
- প্রতিটি অংশের শুরুতে `/* ---- নাম ---- */` ব্লক-কমেন্ট (ফাইলের সূচিপত্র দেখুন)। কোনো লাইব্রেরি নেই; বাইরের কোড
  `public/assets/vendor/`-এ, অপরিবর্তিত।
- বাইরের CDN/স্ক্রিপ্ট নয়; সবকিছু সাইটের নিজের ডোমেইন থেকে (CSP)।

## ৫. কমিটের আগে

1. প্রতিটি `.php` ফাইলে `php -l <ফাইল>` (সিনট্যাক্স)।
2. পেইজ ডেস্কটপ (১৯২০, ১৪৪০) ও মোবাইল (৩৯০) দুটোতে দেখুন; পাশে স্ক্রল বার যেন না আসে।
3. ছোট, একটা-কাজের কমিট; বার্তা কী বদলেছে বলে।
4. `PROGRESS.md` হালনাগাদ; সিদ্ধান্ত বদলালে `CLAUDE.md`।
